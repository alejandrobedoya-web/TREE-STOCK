# Guía de uso de Tree Stock

## Objetivo

Tree Stock es una aplicación Java de inventario que permite gestionar productos mediante un menú en consola. Su objetivo es almacenar productos, visualizar el inventario y buscar elementos por su código.

## Instrucciones de ejecución

1. Abre una terminal o consola.
2. Navega hasta la carpeta del proyecto:
   ```bash
   cd "d:\MIS DOCUMENTOS\PERSONAL\ESTUDIOS\IU DIGITAL\DESARROLLO DE SOFTWARE\MiProyectoJava\TREE STOCK\src"
   ```
3. Compila los archivos Java:
   ```bash
   javac Main.java Producto.java ArbolInventario.java
   ```
4. Ejecuta la aplicación:
   ```bash
   java Main
   ```

## Uso de la aplicación

- Al iniciar, el programa mostrará un menú con las opciones disponibles.
- Selecciona la opción correspondiente para insertar un producto, listar inventario o buscar un producto.
- Para insertar, ingresa los datos solicitados como código, nombre, categoría y cantidad.
- Para buscar, ingresa el criterio de búsqueda y la aplicación mostrará los resultados encontrados.
